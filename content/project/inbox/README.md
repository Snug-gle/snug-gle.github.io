# Project Inbox

> 새로운 아이디어와 빠른 캡처를 위한 임시 공간

## 사용 방법

### 1. 빠른 캡처
- 새로운 프로젝트 아이디어
- 떠오르는 기술 노트
- 나중에 정리할 내용

### 2. 주간 처리 (Weekly Review)
매주 inbox를 비우고 다음 중 하나로 처리:
- **Project**: `active/` 또는 `pending/`으로 이동
- **Area**: 적절한 영역으로 이동 (career, work, learning)
- **Resource**: 학습 자료로 분류 (book, lecture, topics)
- **Archive**: 더 이상 필요 없는 내용

### 3. Inbox Zero 원칙
- 목표: 매주 금요일까지 inbox를 비우기
- inbox에 1주일 이상 머물러서는 안 됨
- 빈 inbox = 깔끔한 마음

## 현재 상태
