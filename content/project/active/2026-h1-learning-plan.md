| 자격증 | 일정 | 비고 |
|--------|------|------|

### 3월 (현재) — 기초 다지기

시험이 없는 유일한 준비 기간. 모든 과목의 기반을 동시에 닦는다.

| 주차 | 학습 내용 |
|------|---------|
| 3/1 ~ 3/8 | 정처기 필기 범위 파악 + 기출 1회분 풀어보기 (현재 수준 진단) |
| 3/9 ~ 3/15 | 정처기 필기: 소프트웨어 설계 / 소프트웨어 개발 |
| 3/16 ~ 3/22 | 정처기 필기: 데이터베이스 구축 / 프로그래밍 언어 활용 |
| 3/23 ~ 3/31 | 정처기 필기: 정보시스템 구축 관리 + **트랜잭션/DB 락 심화 시작** |

**코틀린**: 매일 30분, Kotlin Koans 온라인 연습 병행 (부담 없이 시작)

### 4월 — 정처기 + SQLD 동시 준비 / 원서접수

| 4/13 ~ 4/19 | SQLD: SQL 기본/활용 (윈도우 함수, 서브쿼리, 집합 연산자) |
| **4/20 ~ 4/23** | **정처기 필기 원서접수** ← 놓치면 안 됨 |
| 4/24 ~ 4/26 | 정처기 필기 최종 정리 + 오답 노트 |
| **4/27 ~ 5/1** | **SQLD 원서접수** ← 놓치면 안 됨 |

**트랜잭션/DB 락**: 격리수준 4단계 + InnoDB 잠금 메커니즘 정리 (4월 중 완성 목표)

## 주제별 학습 전략

### 정보처리기사 필기

5과목, 과목당 20문항, 과락 40점 / 평균 60점 합격

| 과목 | 난이도 | 전략 |
|------|--------|------|
| 소프트웨어 설계 | 중 | UML, 디자인 패턴 용어 암기 |
| 소프트웨어 개발 | 중 | 테스트 기법, 버전 관리 |
| 데이터베이스 구축 | **쉬움** | 현재 실력으로 고득점 가능 |
| 프로그래밍 언어 활용 | 중 | C/Java/Python 코드 독해 |
| 정보시스템 구축 관리 | **어려움** | 암기량 많음 → 기출 반복이 답 |

- 추천 교재: 수제비 (기출문제 위주)
- 목표: 각 과목 60점 이상, 과락 없음

### SQLD

2과목 구성, 60점 이상 합격 (단, 과목별 40점 과락 있음)

| 과목 | 비중 | 핵심 |
|------|------|------|
| 데이터 모델링의 이해 | 30% | **ERD, 정규화(1NF~BCNF), 엔티티/관계** ← 취약점 |
| SQL 기본 및 활용 | 70% | 윈도우 함수, 계층 쿼리, 집합 연산자 |

- SQL 실력은 있으니 **데이터 모델링 파트 집중**
- 기출 최소 3회분 완주 필수
- [[resource/topics/database/잠금]], [[resource/topics/database/교착 상태]] 연계 학습

### AWS CLF-C02

4개 도메인, 700점 이상 합격 (1000점 만점)

| 도메인 | 비중 |
|--------|------|
| 클라우드 개념 | 24% |
| 보안 및 규정 준수 | 30% |
| 클라우드 기술 | 34% |
| 결제, 요금 및 지원 | 12% |

- 기존 [[resource/topics/aws/_AWS MOC]] 기반 활용
- Udemy "AWS CCP" 강의 + AWS Skill Builder 무료 모의고사
- 3~4주 집중으로 충분. **6월에 몰아서 해도 됨**

### 코틀린

기존 자산: [[resource/topics/algorithms/자바 알고리즘 인터뷰 with 코틀린]] 보유

**3월 ~ 6월 단계별 목표**:
1. **3월**: Kotlin Koans 온라인 (기초 문법 감잡기)
2. **4월**: null safety, 확장 함수, 람다, 고차 함수
3. **5월**: data class, sealed class, object, 코루틴 기초
4. **6월**: Spring Boot + Kotlin 통합 실습 (Linkwave 일부 전환 실험)

### 트랜잭션 / DB 락 (3~4월 완성 목표)

기존 자산: [[resource/topics/database/잠금]], [[resource/topics/database/교착 상태]] 기초 있음

**심화 학습 체크리스트**:
- [ ] ACID 속성 + 각 속성 위반 사례 정리
- [ ] 격리 수준 4단계별 이상 현상 실제 DB에서 재현
  - READ UNCOMMITTED → Dirty Read
  - READ COMMITTED → Non-Repeatable Read
  - REPEATABLE READ → Phantom Read (MySQL InnoDB는 어느 정도 방지)
  - SERIALIZABLE
- [ ] InnoDB 잠금 종류: 레코드/갭/넥스트키/테이블/인텐션 잠금
- [ ] Deadlock 발생 조건 4가지 + 탐지/회피 전략
- [ ] Spring @Transactional propagation 7가지 정리
- [ ] Optimistic Lock (`@Version`) vs Pessimistic Lock (`@Lock`) 구현 비교
- [ ] Redis 분산 락 (Redisson) 구현
- [ ] 결과물: `resource/topics/database/트랜잭션-심화.md` 작성
