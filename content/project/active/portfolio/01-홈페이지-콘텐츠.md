## Philosophy (개발 철학)

### 핵심 원칙 3가지

#### 1. 측정한다 (Measure)
```
"추측이 아닌 측정으로 개선한다"

- React DevTools Profiler로 병목 지점 파악
- Chrome DevTools로 네트워크 요청 분석
- EXPLAIN으로 쿼리 실행 계획 확인
```

#### 2. 개선한다 (Improve)
```
"점진적 개선의 힘을 믿는다"

- Performance Tester: 100 → 500 → 1000개 페이징
- LinkWave: 단일 테이블 → 월별 파티션
- 완벽한 설계는 없다, 지속적 개선이 중요
```

#### 3. 문서화한다 (Document)
```
"배운 것을 공유한다"

- PARA 방법론으로 체계적 관리
- 프로젝트 아키텍처 문서 작성
- 학습 노트를 블로그로 공개
```
