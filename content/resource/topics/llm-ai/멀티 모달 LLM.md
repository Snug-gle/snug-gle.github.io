- 멀티모달 대규모 언어 모델(Multimodel Large Language Models, LLMs)은 텍스트뿐만 아니라 이미지, 비디오등 여러 형태의 데이터를 이해하고 처리할 수 있는 인공지능 모델
- 주요 기능
	- 데이터 융합: 다양한 모달리티의 데이터를 결합하여, 각각의 데이터 유형에서 얻을 수 있는 정보의 이점을 최대화함
	  ex. 이미지의 시각정보 + 이미지에 대한 설명 텍스트
	- 상호 작용 이해: 멀티모달 모델은 텍스트와 이미지 사이의 상호 작용을 이해할 수 있음
	  ex. 이 사진 속 개는 무엇을 하고 있나요? -> 공을 물고 뛰고 있습니다.
	- 복합적 질의 응답: 텍스트와 이미지를 포함한 복합적 질의에 대해 응답할 수 있음
	  ex. 의료 이미지 진단, 멀티미디어 콘텐츠 검색
- 예시
	- OpenAI의 CLIP: 텍스트와 이미지를 함께 이해하고, 텍스트 설명이 이미지와 얼마나 잘 일치하는지를 평가할 수 있는 모델
	- OpenAI의 DALL-E: 텍스트 설명을 바탕으로 새로운 이미지를 생성할 수 있는 능력을 가지고 있음. "그림을 그리는 AI"
	- LLaMA: 대규모 언어 모델로 복잡한 언어 이해 작업을 처리하는 데 최적화. 다양한 언어와 자연어 처리(NLP)
	- Google이 Multimodal LLMs: 여러 유형의 데이터를 처리할 수 있도록 설계된 모델로, 텍스트, 이미지, 탭 데이터(tabular data)등을 동시에 이해할 수 있음
