- 트랜스포머 아키텍처는 자연어 처리(NLP) 분야에서 널리 사용되는 모델 구조
	- 주요 구성 요소
		- 셀프 어텐션(Self-Attention) 메커니즘: 입력 시퀀스 내 각 단어(또는 토큰)가 서로에게 얼마나 중요한지를 계산하여 각 단어가 시퀀스 내 다른 단어와 어떻게 상호 작용하는지를 학습. -> 이를 통해 모델은 데이터의 중요한 부분에 집중할 수 있음
		- 멀티-헤드 어텐션: 셀프 어텐션을 여러 번 병렬로 수행하여 다양한 부분에 집중할 수 있게 함 -> 다양한 관점에서 정보를 처리하도록 도와줌
		- [[포지셔널 인코딩(Positional Encoding)]]: 트랜스포머는 입력 데이터의 순서 정보를 자동으로 감지하지 못하기 때문에, 입력 데이터의 위치 정보를 제공하는 포지셔널 인코딩을 사용함. -> 모델은 단어의 순서와 관계를 이해할 수 있음
		- 피드 포워드 신경망: 각 어텐션 블록 후에는 피드 포워드 신경망이 적용되어, 어텐션 메커니즘의 출력을 처리하여 다음 레이어로 전달
		- 레이어 정규화와 잔차 연결: 각 서브 레이어(어텐션과 피드 포워드 신경망)의 출력에는 잔차 연결(residual connection)이 추가되고, 이어서 레이어 정규화가 수행됨 -> 학습 과정을 안정화시키고, 더 깊은 네트워크 에서도 효과적인 학습을 가능하게 함
	- 장점
		- 병렬 처리: 트랜스포머는 RNN(순환 신경망)과 달리 시퀀스의 각 요소를 동시에 처리할 수 있어 학습 시간이 단축
		- 장거리 의존성 학습: 셀프 어텐션 메커니즘 덕분에, 트랜스포머는 텍스크 내 멀리 떨어진 요소 간의 관계를 잘 파악할 수 있음

## 어텐션
- 어텐션 메커니즘
	- 어텐션 메커니즘은 주어진 쿼리에 대해 키와 값 쌍을 가지는 입력들 사이의 관계를 계산하여 어떤 입력 부분이 중요한지를 결정하는 방법

## 정규화와 피드 포워드 층
- 정규화: 딥러닝 모델에서입력이 일정한 분포를 갖도록 만들어 학습이 안정적이고 빨라질 수 있도록 하는 기법
