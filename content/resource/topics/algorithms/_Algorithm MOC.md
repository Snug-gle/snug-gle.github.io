## 📊 자료구조

### 선형 자료구조
- **Array** (배열)
- **Linked List** (연결 리스트)
- **Stack** (스택)
- **Queue** (큐)
- Deque (덱)

### 비선형 자료구조
- **Tree** (트리)
  - Binary Tree
  - Binary Search Tree
  - AVL Tree
  - Red-Black Tree
- **Graph** (그래프)
- **Heap** (힙)
- **Hash Table** (해시 테이블)

## 🔍 정렬 & 탐색

### 정렬 알고리즘

- Bubble Sort

- Insertion Sort
- Merge Sort
- Quick Sort

### 탐색 알고리즘

## 🧩 알고리즘 패러다임

### 기본 기법
- **Greedy** (탐욕법)

- Two Pointers
- Sliding Window
- 비트 연산
