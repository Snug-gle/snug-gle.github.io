# Topics - 기술 주제별 노트

> 개발 지식을 주제별로 정리한 참고 자료

## Map of Content (MOC)

주제별 지식의 허브 역할을 하는 MOC 파일들:

### Backend
- [[_Java MOC]] - Java 언어 핵심 개념
- [[_Spring MOC]] - Spring Framework 생태계
- [[_Database MOC]] - 데이터베이스 이론 및 최적화

### Frontend
- [[_React MOC]] - React 라이브러리 및 생태계
- [[_Vue MOC]] - Vue.js 프레임워크
- [[_TypeScript MOC]] - TypeScript 타입 시스템

### Architecture & Design
- [[_Architecture MOC]] - 소프트웨어 아키텍처 패턴
- [[_Algorithm MOC]] - 알고리즘 및 자료구조

### DevOps & Cloud
- [[_Infrastructure MOC]] - 인프라 및 DevOps
- [[_AWS MOC]] - AWS 클라우드 서비스

### AI & Data
- [[_LLM & AI MOC]] - LLM 및 AI 애플리케이션

## 디렉토리 구조

```
topics/
├── algorithms/          # 알고리즘 관련 노트
├── architecture/        # 아키텍처 패턴
├── aws/                # AWS 서비스
├── database/           # 데이터베이스
├── frontend/           # 프론트엔드 기술
│   ├── react/
│   ├── typescript/
│   └── vue/
├── infrastructure/     # 인프라 및 DevOps
├── java/              # Java 언어
├── llm/               # LLM 및 AI
└── spring/            # Spring Framework
```

## 사용 방법

1. **MOC부터 시작**: 관심 주제의 MOC 파일 확인
2. **링크 탐색**: MOC에서 관련 노트로 이동
3. **새 노트 추가**: 관련 MOC에 링크 추가
4. **상호 연결**: 관련 주제 간 링크 생성
