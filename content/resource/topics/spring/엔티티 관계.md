- OneToMany...
	- mappedBy = "A"
		- 연관관계의 주인을 설정하는 속성
		- A 필드가 연관관계 주인
		- A 필드가 있는 클래스에 FK가 있음
	- fetch = FetchType.LAZY
		- 연관된 데이터를 언제 로드할지 정하는 옵션
		- 지연로딩
		- 해당 필드 B일때, B.get()을 호출할 때 쿼리가 나감
	- cascade = CascadeType.ALL
		- 부모 엔티티를 저장/삭제할 때 자식 엔티티도 자동으로 처리하는 옵션
		- persist, merge, remove 등 모든 작업이 전파됨
	- orphanRemoval = true
		- 부모 엔티티의 컬렉션에서 자식 엔티티가 제거되면 해당 자식 엔티티를 DB에서도 삭제
