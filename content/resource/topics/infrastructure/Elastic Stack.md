- Elasticsearch, Logstash, Kibana, Beats
- Elasticsearch
	- Apache Lucene 기반의 Full-text 검색 기능을 강화한 오픈소스 검색 엔진
	- REST API를 이용해 명령 가능, 대량의 데이터를 빠르게 저장, 검색, 분석이 가능
- Logstash
	- 파이프라인을 생성해서 데이터를 input, filter, output하는 역할을 수행하는 도구
	- input: 데이터 수집
	- filter: 필터링
	- output: ElasticSearch로 전송
- Kinaba
	- Elasticsearch에 저장된 데이터를 시각화 하고 모니터링 해주는 도구
	- Discover, Visualize, Dashboard등
- Beats
	- 생성된 데이터 혹은 로그를 Logstash or Elasticsearch로 전송해 주는 가볍고 빠른 로그 수집 도구
