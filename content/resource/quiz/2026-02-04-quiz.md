## Q2. 역할 기반 분리 - 기술 스택 선택

**질문**: 다음 상황에서 JPA와 MyBatis 중 어떤 것을 사용해야 하나요?

> "사용자 프로필 수정 화면에서 '저장' 버튼을 눌러 이름과 이메일을 변경"

<details>
<summary>정답 보기</summary>

**정답**: JPA (Command Layer)

**해설**: 
- 엔티티의 상태를 변경해야 하므로 JPA 사용
- 조회 → 수정 → Dirty Checking 자동 저장 패턴 적용
- `userRepository.findById()` → `user.updateProfile()` → JPA가 자동 저장

```java
@Transactional
public void updateProfile(UUID userId, UpdateRequest request) {
    User user = userRepository.findById(userId).orElseThrow();
    user.updateProfile(request.getName(), request.getEmail());
    // Dirty Checking으로 자동 저장
}
```

**관련 노트**: [[역할 기반 분리 CQRS]]
</details>

## Q4. Mockito - @Mock vs @MockitoBean

**질문**: 다음 코드의 문제점은 무엇인가요?

```java
@ExtendWith(MockitoExtension.class)
class UserServiceTest {
    @MockitoBean  // ← 문제!
    private UserRepository userRepository;
}
```

<details>
<summary>정답 보기</summary>

**정답**: `@MockitoBean`은 Spring 컨텍스트 없이 사용할 수 없음

**해설**: 
- `@ExtendWith(MockitoExtension.class)`는 순수 Mockito 환경 (Spring 없음)
- `@MockitoBean`은 Spring Boot의 어노테이션으로 `@SpringBootTest` 등과 함께 사용해야 함
- 순수 단위 테스트에서는 `@Mock`을 사용해야 함

**수정된 코드**:
```java
@ExtendWith(MockitoExtension.class)
class UserServiceTest {
    @Mock  // ✅ 순수 Mockito 환경에서는 @Mock 사용
    private UserRepository userRepository;
}
```

**관련 노트**: [[Mockito 테스트 어노테이션]]
</details>

## Q5. Mockito - ArgumentCaptor

**질문**: `ArgumentCaptor`는 어떤 목적으로 사용하며, 언제 필요한가요?

<details>
<summary>정답 보기</summary>

**정답**: Mock 메서드에 전달된 인자를 캡처하여 검증할 때 사용

**해설**: 
- 서비스가 Repository에 어떤 엔티티를 저장했는지 검증할 때 유용
- `verify()`만으로는 저장된 객체의 내부 값을 확인할 수 없음
- `ArgumentCaptor`로 인자를 캡처하여 상세 검증 가능

```java
@Captor
ArgumentCaptor<Contact> contactCaptor;

@Test
void createContact_Success() {
    // when
    contactService.createContact(userId, request);
    
    // then
    verify(contactRepository).save(contactCaptor.capture());
    Contact savedContact = contactCaptor.getValue();
    assertThat(savedContact.getName()).isEqualTo("홍길동");
    assertThat(savedContact.getPhone()).isEqualTo("010-1234-5678");
}
```

**관련 노트**: [[Mockito 테스트 어노테이션]]
</details>
