- 여러가지 도구가 있지만, 결국 형태만 다를 뿐 모니터링하려는 값은 동일
	- CPU, 메모리, TPS(초당 처리량)를 확인하는 것이 핵심
- 로컬 모니터링
	- 내 컴퓨터에서 도커 환경을 구축하여 여러 대의 컴퓨터를 시뮬레이션하는 방식
	- 도커를 사용하여 컴퓨터 자원을 분할하고 이를 마치 여러 대의 독립적인 컴퓨터처럼 운영할 수 있음
	- 도커, Prometheus, Grafana를 활용
- 클라우드 모니터링
	- 실제로 분리된 인스턴스를 띄워 각 인스턴스의 사용량을 모니터링 할 수 있음
	- AWS CloudWatch를 활용
- 도커
	- "소프트웨어 환경의 일관성 문제"를 해결하기 위해 등장
		- 개발 환경에서 잘 돌아가는 애플리케이션을 배포할 때마다 운영 환경에서는 제대로 작동하지 않는 문제가 발생하곤 했음(환경차이)
		- "애플리케이션과 그 실행에 필요한 환경을 하나의 단위로 묶어서 실행"
			- 컨테이너라는 독립적인 환경에서 실행하도록 만들어 환경에 구애받지 않고 어디서나 똑같이 실행될 수 있게 함
