### 아키텍처
- 수치화를 하기 위해서는 우선 아키텍처를 이해해야
- 아키텍처: 소프트웨어 아키텍처는 시스템의 기본 구조이며, 시스템을 구성하는 요소와 각 요소 간의 관계를 정의하는 일종의 청사진
	- 예
		- 3-Tier Architecture: 프론트엔드에서 값을 받아 -> 웹서버(스프링) -> 데이터베이스
			- 클라이언트: 브라우저에서 요청을 보냄
			- 서버: 요청을 처리하고 데이터베이스와 소통
			- 데이터베이스: 데이터를 저장하고 서버의 요청을 처리
	- 시스템이 커지면.. 
		- + 메시지 큐, API Gateway 등등 추가되어 복잡해짐
- 아키텍처는 시스템의 요소들이 어떻게 연결되고 데이터를 주고 받는지를 나타내는 관계도
### 병목현상
- 특정 구간에서 일정량의 트래픽을 해소하지 못하게 됨
- 모니터링이 필요함
	- 모니터링: 각 시스템 간 구성 요소들이 어떤 식으로 동작하고 있는지 살펴보고 개선할 수 있음
