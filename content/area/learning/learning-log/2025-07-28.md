## 🧠 LangGraph + LangChain 기반 A2A 주식분석 서비스

### 💡 컨셉 요약

사용자는 금융 AI 도우미와 대화하며, 주식 관련 뉴스·공시·차트·종목 발굴·전략 수립 등 실전 분석을 수행한다. 모든 질문은 LangGraph로 구성된 분기 흐름을 따라 LLM이 처리한다. 이 과정에서 A2A(Agent-to-Agent)로 협업하고, MCP로 플러그인 모듈형 연동을 지원한다.

---

## 📌 사용 기술 스택

| 구성       | 기술                                                      |
| -------- | ------------------------------------------------------- |
| 프론트엔드    | React, TypeScript, Vite, TailwindCSS                    |
| 백엔드      | Spring Boot (Java or Kotlin) + REST API                 |
| AI & LLM | LangChain, LangGraph, OpenAI GPT-4o                     |
| A2A 플로우  | CrewAI, AutoGen                                         |
| 데이터      | 주식 뉴스 API, 공시 API, 차트 데이터 (업비트/코스피), 정형 데이터 CSV         |
| DB       | PostgreSQL or MongoDB (로그 저장용)                          |
| 기타       | FastAPI (Agent Proxy), Redis, LangSmith (LLM Debugging) |
## 😎 클라이언트에게 제공할 수 있는 매력

- ✅ AI에게 자유롭게 주식/금융 질의 가능
- ✅ 에이전트들이 전략적으로 협업하여 고급 분석 제공
- ✅ 공시/뉴스/지표/기술적 분석을 연계하여 판단 근거 제공
- ✅ 시각화된 리포트와 종목 추천 제공
- ✅ 자동화된 시나리오 대응 (예: 'FOMC 뉴스 나오면 어떻게 반응해?')

---

## 📍 사용자 시나리오 흐름

### 🎯 시나리오: "이번 주 가장 주목할 이슈 종목이 뭐야?"

1. 사용자는 "이번 주 주목 종목" 질의
2. LangChain → LangGraph 로 분기
    
    - 1️⃣ 공시 데이터 수집 Agent 실행
    - 2️⃣ 뉴스 크롤링 Agent 실행
    - 3️⃣ 기술적 분석 Agent 실행
        
3. A2A 기반으로 각 Agent 결과를 하나의 리포트로 병합
4. MCP에서 종목 상세 정보를 가져와 시각화
5. 사용자에게 테이블+텍스트+그래프 형태로 응답
