## 스케치
- orderNumber 필드
- 기존
	- 행 이동이 가능하다
		- 행 이동 시 순서가 변경된다
	- 행 추가 시 동시 여러 줄이 가능하다
		- 행 추가 시 최초 index는 상단에 추가된다.
	- 빈 값이 있는지 없는 지 체크한다
- 변경
	- @dropEnd = dropEnd 이벤트로 드랍 시 인덱스를 새로이 업데이트
		- fromRowIndex: event 객체 요소, 드래깅된 시점의 행 인덱스
		- toRowIndex: 드랍되는 그리드의 드랍시점의 행인덱스

		드래그 동작 시 orderName이 수정되어야, 추후 find가 됨
