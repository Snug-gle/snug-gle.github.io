## 요구 사항
- 트리 메뉴에서 하위 메뉴에 권한 혹은 usable이 있어도, 상위 메뉴를 사용하지 않는다면, 하위 메뉴를 볼 수 없다.

## 스케치
### 토의
- 예외 처리만 했으며, 로직이 추가되어야 함
### 소스 확인
#### buildMenuTree
- 메뉴 아이템을 받아 메뉴 트리를 반환한다
- 사용 가능한 아이템들을 추출하여 entityId를 키로 하는 메뉴 맵으로 형태로 변환한다
``` json
menuMap = {
  24: {
    name: "USER_MANAGEMENT",
    label: "사용자 관리",
    icon: null,
    actionType: "TAB",
    orderNumber: 1
  },
```
- 사용 가능 아이템들을 순회하며
	- 순회하는 아이템이 상위 메뉴 아이디가 없으면 메뉴 트리에 아이템을 넣는다(상위 메뉴 처리)
##### AS -IS
- 순회하는 아이템이 상위 메뉴 아이디가 있으면 상위 아이템의 children에 해당 아이템을 넣는다
##### 임시 예외 조치
- 순회하는 아이템이 상위 메뉴 아이디가 있는데
	- 그 상위 메뉴가 true 하면
		-  상위 메뉴의 children에 아이템을 넣는다
	- 그 상위 메뉴가 falsy하면
		- 경고: 부모메뉴 없음
##### 고려 해야할 사항
- 기존 로직은 사용 가능한 아이템이면 무조건 넣는다
	~~-  ? 하위 메뉴에만 권한이 있는 사람이 상위 메뉴에 접근해도 괜찮을까 ? ~~
	- 다른 하위 메뉴에는 권한이 없으니 상관 없을 듯
	- ? 만약 하위 메뉴는 사용 가능 인데 상위 메뉴가 usable 하지 않다면 ?
		- ? 상위 메뉴는 무조건 usable ?
		- ? 하위 메뉴의 상위 메뉴가 usable 하지 않으면 하위 메뉴를 트리에 넣어야 하나 ?
- 임시 조치는 하위 메뉴가 usable하더라도 상위 메뉴가 falsy 하면 부모 메뉴가 없다고 예외처리
	- ? 부모가 falsy한 경우는 무엇이 있을까
		- 하위 메뉴가 usable 하지만 상위 메뉴가 usable 하지 않은 경우
			- 지금 메뉴 트리는 usable 한 메뉴만 대상으로 처리하고 있다
		- 하위 메뉴가 usable 하지만 상위 메뉴에 접근 권한이 없는 경우
			- ? usable과 권한에 대해 이해가 더 필요하다
