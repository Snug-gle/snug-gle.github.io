# 📁 Areas

> 지속적으로 관리하는 책임 영역 (끝이 없는 것들)

## 🌱 영역별 현황

### [[career/Why Developer|💼 Career Development]]
개발자로서의 성장과 커리어 관리
- 기술 역량 개발
- 포트폴리오 관리
- 네트워킹

### [[learning/learning-log/README|📚 Learning Journey]]
지속적인 학습과 성장
- **learning-log/**: 학습 일지, 회의록
- **study-plans/**: 학습 계획 및 로드맵

### [[work/README|🏢 Work Notes]]
현재 직장 업무 관련
- **branch/**: 브랜치별 작업 (mafra 등)
- **meeting/**: 회의록

## 🔄 Area vs Project 차이

| | Area | Project |
|---|------|---------|
| 기간 | 지속적 | 일시적 |
| 목표 | 유지/개선 | 명확한 완료 |
| 예시 | 건강, 커리어 | 블로그 런칭 |

## 📖 PARA 원칙
Areas는:
- ❌ 완료되지 않음 (끝이 없음)
- ✅ 꾸준한 관리 필요
- ✅ 삶의 여러 측면을 대표

방치된 Area는 Archive로 이동하세요.
