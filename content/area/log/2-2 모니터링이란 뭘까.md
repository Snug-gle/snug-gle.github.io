- 모니터링이란?
	- 컴퓨터들 사이의 관계도 -> 아키텍처, 컴퓨터 간의 통신하는 관계 -> 도로
	- 컴퓨터 성능을 판단하는 요소
		- CPU
			- 연산과 명령어 처리를 담당
		- 메모리
			- 데이터를 임시 저장하고 연산을 돕는 역할
			- 작업공간
	- 3-Tier 에서는 어디서 사용할까?
		- 프론트엔드
			- CPU 중심으로 동작
				- 브라우저에서 렌더링
			- 메모리
				- DOM 요소, 캐시 데이터, 렌더링 데이터 등으로 메모리를 소비
			- 결론: 복잡한 DOM 구조나 대량 데이터 처리 시 메모리 사용이 높아질 수 있음
		- 서버
			- CPU
				- 클라이언트 요청 처리, 비즈니스 로직 실행, 암호화/복호화, 데이터 변환, 직렬화 등
			- 메모리
				- 캐시(예: Redis), 세션 데이터, API 응답 생성 시 사용.
			- 결론: 서버는 CPU와 메모리를 균형 있게 사용. 동시 요청이 많거나 비즈니스 로직이 복잡해질수록 사용량 증가
		- 데이터베이스
			- 메모리 중심
				- 인덱스 캐싱, 쿼리 결과 캐싱, 버퍼 풀 등으로 디스크 I/O를 줄이기 위해 메모리 사용
			- CPU 사용
				- 쿼리 실행, 인덱스 검색, 데이터 처리(ex. JOIN, GROUP BY등) 
			- 결론: 메모리 의존도가 높지만, 복잡한 쿼리 실행 시 CPU 사용량도 증가할 수 있음
