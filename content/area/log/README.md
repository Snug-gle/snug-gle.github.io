```

│   ├── 2026-01-22.md

```

## 주간 리뷰 (계획)

매주 일요일에 한 주를 돌아보고 다음 주를 계획:
- 주요 성과
- 도전 과제
- 다음 주 목표

## 월간 회고 (계획)

매월 마지막 주에 한 달을 정리:
- 프로젝트 진행 상황
- 학습한 기술
- 성장 포인트
- 다음 달 계획
