# WebConsole — 상담 시스템

**기간**: 2024.03 ~ 2025.09 | **역할**: Backend/Frontend Developer

> 고객 상담 업무를 지원하는 내부 웹 시스템 — 첫 실무 프로젝트

---

## 프로젝트 개요

B2B 고객 상담 운영 팀을 위한 내부 시스템. SMS 알림, 콜백 관리, 캠페인 운영, 접속 로그 등 상담 업무 전반을 지원한다.

**기술 스택**
- Backend: Spring Boot, Java, Oracle DB
- Frontend: Vue.js
- 협업: Git, GitLab, QA 프로세스

---

## 담당 기능 (15개+)

| 카테고리 | 기능 |
|----------|------|
| 메시지 | SMS 메시지 리스트, 알림 관리 |
| 고객 | 고객 정보 관리, 악성 민원 관리 |
| 운영 | 콜백 관리, 캠페인 관리, 사이트 링크 관리 |
| 시스템 | 메뉴 관리, 접속 로그 관리, 상담 유형 관리 |
| QA | 기능 테스트, 이슈 트래킹 |

---

## 배운 점

**기술적 측면**
- Spring Boot CRUD 패턴 체득 (Controller → Service → Repository)
- Oracle DB 설계 및 쿼리 최적화 첫 경험
- Vue.js 컴포넌트 기반 개발

**협업 측면**
- Git 브랜치 전략, 코드 리뷰 프로세스 첫 경험
- GitLab 이슈 트래킹 + QA 사이클 참여
- 팀 개발 환경에서의 커뮤니케이션

---

## 이 프로젝트의 의미

첫 실무 프로젝트로서 "학교에서 배운 것"과 "실제 서비스 개발"의 차이를 몸으로 익힌 시기. 이후 LinkWave에서 아키텍처 결정을 주도할 수 있었던 기반이 됐다.
