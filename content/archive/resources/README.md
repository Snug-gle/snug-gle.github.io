# Archived Resources

> 구 버전 학습 자료 및 더 이상 사용하지 않는 기술 자료

## 아카이브 기준

### 자료를 여기로 이동하는 경우
- ✅ 기술의 메이저 버전 업데이트 (예: Spring Boot 2.x → 3.x)
- ✅ 더 이상 사용하지 않는 프레임워크/라이브러리
- ✅ 대체 기술로 전환 완료
- ✅ 오래된 강의 노트 (2년 이상 경과)

### 이동 절차
1. 새 버전/대체 기술 노트 생성
2. 구 버전 자료에 "Archived" 태그 추가
3. `resource/`에서 `archive/resources/`로 이동
4. MOC에서 참조 제거 또는 "구 버전" 표시

## 보관 중인 자료

_현재 보관된 자료가 없습니다._

## 보관 vs 삭제

### 보관해야 할 경우
- 역사적 참고 가치가 있음
- 마이그레이션 가이드로 활용 가능
- 구 버전 유지보수 필요 가능성

### 삭제해야 할 경우
- 명백히 틀린 정보
- 완전히 쓸모없어진 기술
- 중복된 임시 노트
