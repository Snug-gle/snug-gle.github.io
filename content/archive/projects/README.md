# Archived Projects

> 완료되었거나 비활성화된 프로젝트 보관소

## 아카이브 기준

### 프로젝트를 여기로 이동하는 경우
- ✅ 프로젝트 목표 달성 완료
- ✅ 더 이상 활발하게 진행하지 않음
- ✅ 완료 후 3개월 경과
- ✅ 참고용으로만 유지

### 이동 절차
1. 프로젝트 완료 일자 기록
2. 최종 회고 작성 (성과, 배운 점, 개선점)
3. `project/active/`에서 `archive/projects/`로 이동
4. `index.md`의 Active Projects에서 제거
5. `index.md`의 Completed Projects 섹션에 추가 (요약만)
