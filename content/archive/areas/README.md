# Archived Areas

> 더 이상 활동하지 않는 영역 보관소

## 아카이브 기준

### 영역을 여기로 이동하는 경우
- ✅ 더 이상 담당하지 않는 업무
- ✅ 관심사가 변경됨
- ✅ 우선순위가 낮아짐
- ✅ 6개월 이상 업데이트 없음

### 이동 절차
1. 마지막 활동 일자 기록
2. 간단한 종료 노트 작성
3. `area/`에서 `archive/areas/`로 이동
4. `index.md`에서 제거
